# n8n 飞书日程新闻简报 Agent

基于 **n8n + DeepSeek + 飞书开放平台**搭建的个人效率助理，定时查询日程和新闻，生成简报并发送飞书交互卡片。

## 功能

- 查询飞书日历中的日程；
- 读取飞书多维表格中已有的新闻；
- 使用 DeepSeek 整理重点、生成行动建议；
- 通过飞书机器人推送简报。

## 工作流程

```text
定时触发 → AI Agent + DeepSeek
                ↓
       查询日历与多维表格新闻
                ↓
       生成简报 → 发送飞书卡片
```

模型请求调用工具，n8n 执行接口查询，再将结果交回模型生成内容。

## 技术栈

n8n、DeepSeek API、飞书开放平台、HTTP、JSON、Docker。

## 使用方式

1. 在 Docker 中启动 n8n。
2. 安装工作流使用的 `n8n-nodes-feishu-lite` 节点，导入工作流 JSON。
3. 配置 DeepSeek 凭证、飞书应用权限、日历和多维表格。
4. 替换飞书机器人 Webhook。
5. 核对查询范围与时区，手动测试成功后启用定时执行。
